# Math Help Button + Local Tutor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a three-step Help panel (nudge → similar example → this problem) with lesson links to every question of Block 4 Form C, plus an "Ask" box answered by a local server that runs my AI CLI.

**Architecture:** Static pages stay static. `math/help.js` reads a per-form `help.json` and a shared `math/lessons.json`, then draws the panel. `scripts/tutor.mjs` serves `dist/` plus `/api/*` on the home network and runs `claude -p` (or `codex exec`) with tools off. CI-run `scripts/check.mjs` keeps `help.json` in sync with the page's questions.

**Tech Stack:** Plain JS (browser + Node ≥18 ESM), `node:http`, `node:child_process`, `node:test`. No dependencies.

**Spec:** `docs/superpowers/specs/2026-11-15-math-help-design.md`

## Global Constraints

- No new dependencies; repo scripts stay `node scripts/*.mjs`. Run them with `bun run …` (bun is the user's runner).
- The public site (Firebase kok-5th, GitHub Pages) must work unchanged with no server: hints and links work, and the Ask box is hidden.
- Help never appears on printed PDFs (`@media print`), so `bun run math:pdf` output does not change.
- Help paraphrases the book; never paste textbook text. Links go to `https://www.corefocusonmath.com/classrooms/mod/{resource|url}/view.php?id=N`.
- Hint order is fixed: 1 nudge, 2 similar worked example with different numbers, 3 this problem's walkthrough. Steps unlock in order.
- Wording is for a 7th grader, uses the book's notation (`·` for times, stacked fractions via `<span class="f">`).
- AI CLI runs with no tools and no saved session: `claude -p --tools "" --no-session-persistence --strict-mcp-config --model $TUTOR_MODEL` (default `sonnet`), or `codex exec --skip-git-repo-check -s read-only` when `TUTOR_CLI=codex`.
- The log goes to `logs/tutor.jsonl` (gitignored).

## Review Focus

- The CLI is missing, errors or hangs → the panel shows "The tutor isn't available right now" within 60 s; the server stays up. (Task 1 test `ask fails cleanly when CLI missing`.)
- The page is opened from the public site or `file://` → no Ask box and no console errors; hints still work. (Task 3 manual check, step 4.)
- An empty message, one over 500 characters, or an unknown page/question id → 400, and the CLI is never run. (Task 1 test `validateAsk`.)
- "Just tell me the answer" at step 1 → the reply stays within step 1. The prompt must put the step limit after the student message. (Task 1 test `buildPrompt puts limit last`; Task 5 manual check.)
- Double-tapping Send → one request in flight per panel; the button is disabled until the reply arrives. (Task 3 manual check.)

### Task 1: Local tutor server

**Files:**
- Create: `scripts/static.mjs` (the static file handler moved out of `serve.mjs`)
- Modify: `scripts/serve.mjs` (use `serveDist`)
- Create: `scripts/tutor.mjs`, `scripts/tutor-lib.mjs`
- Test: `scripts/tutor-lib.test.mjs`
- Modify: `package.json` (scripts `"tutor": "node scripts/build.mjs && node scripts/tutor.mjs"`, `"test": "node --test scripts/"`), `.gitignore` (`logs/`)

**Interfaces:**
- Produces `serveDist(req, res): Promise<void>` in `scripts/static.mjs`: the current `serve.mjs` behavior unchanged, including the traversal guard.
- Produces, in `scripts/tutor-lib.mjs`:
  - `validateAsk(body): {page, id, step, question, message} | {error: string}`: `page` matches `/^[a-z0-9-]+$/`, `id` matches `/^(I|II|III)(-\d+)?$/`, `step` is an integer 1–3, `question` is 1–3000 chars, and `message` is 1–500 chars after trim.
  - `loadHelp(page): {entries} | null`: reads `math/<page>/help.json` from disk (server-side; hints from the client are never trusted).
  - `buildPrompt({entry, lesson, step, question, message}): string`: tutor rules, then the question, then the hints for steps 1..3 (labelled "seen" for ≤ step and "NOT yet shown, do not reveal" for the rest), then the student message, then a final line restating the step limit.
  - `cliCommand(env): {cmd: string, args: string[]}`: argv from the Global Constraints, chosen by `env.TUTOR_CLI`.
- HTTP (in `tutor.mjs`, `0.0.0.0:${PORT||8080}`):
  - `GET /api/health` → `{ok:true, cli}`
  - `POST /api/ask` (JSON) → `text/plain` reply streamed from the CLI's stdout, with a 60 s timeout; on failure, a `503` with "The tutor isn't available right now."
  - `POST /api/log` `{page,id,step}` → `204`.
  - Each ask and log appends one JSON line `{t, event:"hint"|"ask", page, id, step, message?, reply?}` to `logs/tutor.jsonl`.
  - Everything else → `serveDist`.

- [ ] **Step 1: Write failing tests** in `scripts/tutor-lib.test.mjs` (node:test):
  - `validateAsk`: accepts `{page:'b4-form-c', id:'I-6', step:1, question:'q', message:'why 72?'}`; returns `{error}` for `message:''`, for `message:'x'.repeat(501)`, for `step:4`, for `page:'../x'` and for `id:'IV-1'`.
  - `buildPrompt puts limit last`: with `step:1`, the output contains hint 1 text, contains hint 3 text only after the "do not reveal" label, and its last line contains `step 1`.
  - `cliCommand`: the default `cmd==='claude'`, and args include `'--tools'`, `''`, `'--no-session-persistence'`; with `{TUTOR_CLI:'codex'}`, `cmd==='codex'` and args include `'exec'`.
  - `ask fails cleanly when CLI missing`: start the server on a random port with `PATH` set to an empty dir (spawn `node scripts/tutor.mjs` with `PORT=0`, then read the port from stdout), POST a valid ask, and expect `503`.

### Task 3: Help panel in the page

**Files:**
- Create: `math/help.js`
- Modify: `math/form.css` (panel styles, print hide), `math/b4-form-c/index.html` (add `<script src="../help.js"></script>` after `form.js`), `src/math-form-example.html` (same line, so new forms get it)

**Interfaces:**
- Consumes `help.json`, `lessons.json` (Task 2) and `/api/health`, `/api/ask`, `/api/log` (Task 1).
- On load: fetch `./help.json`. If it fails, do nothing (pages without help are unchanged). Compute ids like `questionIds`. Add a `Help` button to each matching `.q`/`.task`. The panel shows the tag, the lesson links (`target="_blank"`), hint 1, and a "Next hint" button that reveals 2, then 3. A step is never skipped. Probe `/api/health` once (1 s timeout); only if it answers `ok` show a textarea + Send. Send POSTs to `/api/ask` with the current step and the `.q` text (excluding `.ans` and the panel), streams the reply into the panel, and disables Send while in flight. When local, each revealed step POSTs `/api/log`.
- Styles use the existing tokens (`--accent`, `--tint`, `--rule`); `@media print { .help, .helpbtn { display:none } }`.
